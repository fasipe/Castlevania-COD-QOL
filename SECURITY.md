# Security Policy

## Supported Versions

Only the latest release gets fixes. Older releases are not updated: download the latest one from the [Releases](https://github.com/fasipe/Castlevania-COD-QOL/releases) page.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| Older   | No        |

## What Counts

This is a fan-made port that runs on your own computer, so a vulnerability here is anything that lets someone else run code on it, read or change your files, or slip something into what you download. For example:

- A crafted disc image, memory card save or `codport.ini` that makes `codport.exe` run code or write outside its own folder.
- `Setup.bat` or the scripts it runs (`tools/setup`) doing something other than what they say: running code from somewhere unexpected, or writing outside the port's folder, apart from the desktop shortcut and the Visual Studio Build Tools it offers to install.
- A release download that does not match this repository's source.

These are not security issues; open a normal [issue](https://github.com/fasipe/Castlevania-COD-QOL/issues) for them:

- Crashes, freezes or wrong graphics or sound with the real disc image.
- Bugs in the game itself.
- Problems that need someone to have already changed files on your computer.

## Reporting a Vulnerability

Do not open a public issue. Report it privately on the repository's **Security** tab, with **Report a vulnerability**. Include:

- what is affected (the setup, the port, a release) and which version;
- the steps to reproduce it, and a file that shows it if there is one (never a copy of the game's disc or its files);
- what someone could do with it.

This is a project kept in spare time, so answers may take a while. If the report is confirmed, it is fixed in a new release and you are credited, unless you would rather not be. If it is declined, you get the reason.

## Staying Safe

- Download the port only from this repository's [Releases](https://github.com/fasipe/Castlevania-COD-QOL/releases) page, or build it yourself from the source.
- Use an image of your own disc. Never download the game's code or files from someone else: the port builds them from your disc on your computer.

# Política de Segurança

## Versões com Suporte

Só a versão mais recente recebe correções. Versões antigas não são atualizadas: baixe a mais recente na página [Releases](https://github.com/fasipe/Castlevania-COD-QOL/releases).

| Versão  | Suporte |
| ------- | ------- |
| 1.0.x   | Sim     |
| Antigas | Não     |

## O Que Conta

Este é um port feito por fã que roda no seu computador, então uma vulnerabilidade aqui é qualquer coisa que permita a outra pessoa rodar código nele, ler ou alterar seus arquivos, ou colocar algo no que você baixa. Por exemplo:

- Uma imagem de disco, um save de memory card ou um `codport.ini` manipulado que faça o `codport.exe` rodar código ou escrever fora da própria pasta.
- O `Setup.bat` ou os scripts que ele roda (`tools/setup`) fazendo algo diferente do que dizem: rodando código de um lugar inesperado, ou escrevendo fora da pasta do port, tirando o atalho na área de trabalho e o Visual Studio Build Tools que ele oferece instalar.
- Um download de release que não corresponde ao código deste repositório.

Estes não são problemas de segurança; abra uma [issue](https://github.com/fasipe/Castlevania-COD-QOL/issues) normal para eles:

- Travamentos, congelamentos ou gráficos e sons errados com a imagem verdadeira do disco.
- Bugs do próprio jogo.
- Problemas que exigem que alguém já tenha alterado arquivos no seu computador.

## Como Relatar uma Vulnerabilidade

Não abra uma issue pública. Relate em particular na aba **Security** do repositório, em **Report a vulnerability**. Inclua:

- o que é afetado (o Setup, o port, uma release) e qual versão;
- os passos para reproduzir, e um arquivo que mostre o problema se houver (nunca uma cópia do disco do jogo ou dos arquivos dele);
- o que alguém conseguiria fazer com isso.

Este é um projeto mantido no tempo livre, então as respostas podem demorar. Se o relato for confirmado, a correção sai numa nova versão e você recebe o crédito, a não ser que prefira não receber. Se for recusado, você recebe o motivo.

## Para Se Manter Seguro

- Baixe o port só pela página [Releases](https://github.com/fasipe/Castlevania-COD-QOL/releases) deste repositório, ou compile você mesmo a partir do código.
- Use a imagem do seu próprio disco. Nunca baixe o código ou os arquivos do jogo de outra pessoa: o port os gera a partir do seu disco, no seu computador.
